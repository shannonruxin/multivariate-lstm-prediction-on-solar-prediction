# About
Task from NASA Hackathon held on April 2017.

Given multiple variables in time series to predict Solar Radiation. 

**Dependent Variable:** Solar Radiation

**Independent Variable:** Temperature, Pressure, Humidity, WindDirection(Degrees), Speed, TimeSunRise, TimeSunSet

<img width="865" height="146" alt="image" src="https://github.com/user-attachments/assets/d34d27b5-56b2-480e-abc3-85af23e8b1e0" />

**Dataset:** Solar Radiation Prediction 

**View dataset on Kaggle:** https://www.kaggle.com/datasets/dronio/SolarEnergy/data 

These datasets are meteorological data from the HI-SEAS weather station from four months (September through December 2016) between Mission IV and Mission V.
